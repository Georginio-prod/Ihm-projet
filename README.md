## 📌 Présentation

Projet du cours **IHM (Interface Homme-Machine)**, novembre 2023 : un site d'**organisation de mariage** : présentation du couple, services, galerie, liste de cadeaux et contact.
Le site est basé sur le template gratuit **Settle**, adapté et personnalisé
(textes, images, pages) pour l'exercice.

## 📄 Pages

- `index.html`
- `about.html`
- `couple.html`
- `services.html`
- `gallery.html`
- `gifts.html`
- `contact.html`

## 📁 Structure

`index.html` et pages HTML à la racine, `css/`, `js/`, `fonts/`, `images/`.

## 🚀 Lancement

Aucune installation : cloner et ouvrir `index.html` dans un navigateur.

```bash
git clone https://github.com/Georginio-prod/Ihm-projet.git
```

## 🌐 Déploiement

Déployé sur **Vercel** en site statique : <https://settle-wedding-site.vercel.app>.
